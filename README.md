# KERNEL — System Optimizer

Утилита оптимизации Windows 10/11 для игр и повседневной работы. Один `.exe`, без установки, все изменения можно откатить.

**[⬇ Скачать последнюю версию](../../releases/latest)** · [Telegram-канал kernel1lab](https://t.me/kernel1lab)

## Возможности

- **Ускорение и FPS:** схема питания «Максимальная производительность», оптимизация игр в окне и без рамки, G-Sync/FreeSync для всех игр, отключение VBS, Game DVR, акселерации мыши и другое. У каждого твика честное описание: что он реально даёт, а что только для удобства.
- **Меньше фоновых процессов:** телеметрия и её задачи в планировщике, Copilot, Recall и ИИ-компоненты, виджеты, фоновый режим браузеров. Лишние службы (RDP, Xbox, печать, индексация, обновлялки сторонних программ) отключаются по выбору с точным откатом.
- **Драйверы:** поиск и установка одной кнопкой. Для всех устройств — из Windows Update, для видеокарт NVIDIA — последняя Game Ready версия напрямую с серверов NVIDIA с проверкой цифровой подписи.
- **Очистка:** временные файлы, кэш обновлений, шейдеров, дампы и журналы.
- **Приложения:** удаление встроенных приложений Windows, Microsoft Edge и Store.
- **Программы:** установка популярных программ с официальных сайтов.
- **Старт:** базовая настройка свежей Windows — без рекламы, лишних значков и мусора.
- **Журнал:** каждое действие записывается в `%LOCALAPPDATA%\KERNEL\journal.log`.

Перед автонастройкой KERNEL создаёт точку восстановления системы.

## Требования

- Windows 10 или 11, 64-бит
- Microsoft Edge WebView2 Runtime (уже есть почти на всех системах)
- Права администратора (программа запросит их сама)

## Запуск

Скачайте `KERNEL.exe` из [последнего релиза](../../releases/latest) и запустите. Файл не подписан сертификатом, поэтому Windows может показать окно SmartScreen: «Подробнее» → «Выполнить в любом случае».

KERNEL сам сообщает о выходе новых версий.

## Сборка из исходников

Нужен Go 1.24+. Все зависимости лежат в папке `deps/`, сборка работает без интернета.

```
cd kernel-app
go build -ldflags="-H windowsgui -s -w" -o KERNEL.exe .
```

Или просто запустите `build.bat`.

## Структура

| Путь | Что внутри |
|---|---|
| `kernel-app/*.go` | системная логика: твики, службы, драйверы, очистка |
| `kernel-app/ui/` | интерфейс (HTML/JS, вшивается в .exe) |
| `deps/` | вендоренные зависимости (go-webview2 с патчем, golang.org/x/sys) |
| `version.json` | информация о последней версии для проверки обновлений |
