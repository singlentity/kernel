╔══════════════════════════════════════════════════════════╗
║  Перенос проекта KERNEL в Claude Code                    ║
╚══════════════════════════════════════════════════════════╝

Главный плюс: на твоём Windows Claude Code сможет РЕАЛЬНО собирать и
тестировать .exe — то, чего не мог я (у меня Linux без живого Windows).

────────────────────────────────────────────────────────────
ШАГ 1. Поставь что нужно (один раз)
────────────────────────────────────────────────────────────
1. Go 1.24 или новее — https://go.dev/dl/  (поставь, перезапусти терминал,
   проверь: в PowerShell команда  go version  должна что-то вывести).
2. Claude Code — https://claude.com/claude-code  (там инструкция по установке;
   нужен Node.js). Запускается командой  claude  в терминале.
3. WebView2 Runtime — на Windows 11 и почти везде уже есть. Если нет:
   https://developer.microsoft.com/microsoft-edge/webview2/

────────────────────────────────────────────────────────────
ШАГ 2. Распакуй проект
────────────────────────────────────────────────────────────
Распакуй этот архив куда угодно, например в  C:\kernel-src
Внутри будет:
   kernel-src\kernel-app\   — сам код
   kernel-src\deps\         — зависимости (НЕ удаляй, они нужны для сборки)
   kernel-src\CLAUDE.md     — контекст проекта для Claude Code
   kernel-src\build.bat     — быстрая сборка

────────────────────────────────────────────────────────────
ШАГ 3. Собери и проверь, что всё работает
────────────────────────────────────────────────────────────
Вариант А — просто дважды кликни  build.bat  (в папке kernel-src).
Вариант Б — в терминале:
   cd C:\kernel-src\kernel-app
   go build -ldflags="-H windowsgui -s -w" -o KERNEL.exe .
Появится KERNEL.exe — запусти, проверь, что открывается.

Первая сборка может занять минуту (Go компилирует зависимости). Дальше — секунды.

────────────────────────────────────────────────────────────
ШАГ 4. Открой проект в Claude Code
────────────────────────────────────────────────────────────
В терминале:
   cd C:\kernel-src
   claude
Claude Code сам прочитает CLAUDE.md и поймёт структуру. Дальше проси его
как меня: «добавь твик…», «поправь вкладку…». Он сможет сам собирать
(go build) и ты тут же проверяешь .exe на своём железе — это и есть
«более качественно».

────────────────────────────────────────────────────────────
ВАЖНО
────────────────────────────────────────────────────────────
• Папку deps НЕ трогай и НЕ обновляй зависимости из интернета: там моя
  правленая версия go-webview2 (фикс заморозки интерфейса). Подробнее — в CLAUDE.md.
• Собирать только из папки kernel-app (там go.mod).
• Версию приложения меняй в update_windows.go (строка AppVersion).
• Все исходники интерфейса — ui\app.html и ui\app.js (они вшиваются в .exe
  при сборке, отдельно класть не нужно).
